# Задачи (To-Do List)

> Минималистичный и аккуратный веб-сервис для управления списком задач, созданный с помощью AI (**Google Antigravity / Gemini 3.8 Flash High**).

---

## 📌 Выполненные требования ТЗ

1. **Добавление новых задач**: ввод названия, выбор приоритета, категории и срока выполнения.
2. **Отметка выполненных задач**: кастомный минималистичный чекбокс, аккуратное визуальное зачеркивание, обновление счетчиков.
3. **Удаление задач**: удаление в один клик с возможностью мгновенной отмены (`Отменить`) через всплывающее уведомление.
4. **Сохранение списка при перезагрузке**: надежная синхронизация с `localStorage`.
5. **Дизайн и эргономика**:
   - Строгий глубокий черный фон (`#000000`) без шума и лишних текстур.
   - Минималистичная типографика (Apple SF / Inter).
   - Векторные SVG-иконки вместо стандартных эмодзи.
   - Фирменный логотип с прозрачным фоном.
   - Удобная фильтрация (*Все*, *Активные*, *Завершенные*) и поиск в реальном времени.

---

## 🚀 Запуск на localhost

Проект работает на чистом веб-стеке без сборщиков и сторонних зависимостей:

```bash
# Перейдите в папку проекта
cd /Users/millyrock/.gemini/antigravity/scratch/workbench-todo

# Запуск локального сервера
python3 server.py
```

После этого откройте в браузере: **[http://127.0.0.1:8080](http://127.0.0.1:8080)**.
