# WORKBENCH // TASK_REGISTRY

> Минималистичный, тактильный веб-сервис управления задачами (To-Do List), спроектированный по стандарту **«Quiet Workbench» (Monochrome & Deep Obsidian)** и реализованный с помощью AI-ассистента **Google Antigravity (модель Gemini 3.8 Flash High)**.

## 📌 О проекте и выполненных требованиях

Проект разработан в рамках выполнения тестового задания на позицию веб-разработчика / AI-инженера. Все требования задания выполнены в полном объёме:

| Требование ТЗ | Статус | Реализация |
|---|---|---|
| **1. Добавление новых задач** | ✅ Выполнено | Быстрый ввод через форму, поддержка шортката `Enter`, валидация, выбор приоритета (`P1`, `P2`, `P3`), категории и дедлайна. |
| **2. Отметка выполненных задач** | ✅ Выполнено | Пользовательский тактильный чекбокс, аккуратное зачеркивание, фиксация времени завершения, пересчёт метрик прогресса. |
| **3. Возможность удалять задачи** | ✅ Выполнено | Деликатное удаление со всплывающим уведомлением (Toast) и возможностью мгновенной отмены (`[Undo]`), пакетная очистка выполненных. |
| **4. Сохранение при перезагрузке** | ✅ Выполнено | Модуль `Storage` на базе `localStorage` с поддержкой экспорта и импорта JSON, а также эталонными демо-данными. |
| **Аккуратный и выверенный интерфейс** | ✅ Выполнено | Полная синхронизация с дизайн-системой **Workbench UI** из Notion: угольный холст `#080808`, точечная сетка (dot matrix), микро-радиусы 2–4 px, строгие разделители `1px solid #222226`. |

## 🛠️ Архитектура и стек

- **HTML5**: Семантическая доступная разметка (WAI-ARIA атрибуты, структурированные секции, модальные диалоги).
- **CSS3 (Custom Properties & Grid/Flexbox)**:
  - `css/tokens.css` — централизованные дизайн-токены палитры Monochrome & Deep Obsidian, радиусов, сеток и типографики.
  - `css/app.css` — строгие компоненты интерфейса без размытых теней и визуального шума.
- **Modern JavaScript (ES6+ Modules)**:
  - `js/storage.js` — абстракция над `localStorage`, импорт/экспорт дампов задач, восстановление дефолтного состояния.
  - `js/app.js` — контроллер приложения, делегирование событий, динамическая реактивность метрик, фильтрация и горячие клавиши.
- **Python HTTP Server**: Встроенный сервер `server.py` с автоматической настройкой CORS и заголовков кэширования для локального запуска.

## ⚡ Дополнительные возможности Workbench

1. **Метрики и информационная плотность**:
   - Счётчики задач: «Всего», «В процессе», «Завершено».
   - Индикатор прогресса выполнения (Progress bar) в процентах.
2. **Фильтрация и поиск**:
   - Вкладки статуса: *Все*, *Активные*, *Выполненные* со счётчиками.
   - Полнотекстовый поиск по заголовку и тегам в реальном времени.
   - Фильтр по направлениям (`Engineering`, `Design`, `DevOps`, `Research`, `Personal`).
   - Сортировка: по дате добавления, по приоритету, по алфавиту.
3. **Тактильный UX и редактирование**:
   - Двойной клик по задаче для инлайн-редактирования заголовка.
   - Кнопка «Очистить выполненные».
   - Уведомления об операциях с возможностью отмены удаления (`Undo`).
   - Резервное копирование: кнопки «Экспорт JSON» и «Импорт JSON».
4. **Горячие клавиши (Keyboard Navigation)**:
   - `N` или `/` — мгновенный фокус на поле ввода новой задачи.
   - `Enter` — добавить / сохранить изменения.
   - `Esc` — снять фокус / отменить редактирование / закрыть модалку.
   - `?` — шпаргалка горячих клавиш.

## 🚀 Быстрый запуск на localhost

Для запуска не требуются сторонние зависимости (`npm`, `node_modules` и т. д.) — всё работает на чистом веб-стеке.

### Вариант 1: Через готовый скрипт Python (рекомендуется)
```bash
python3 server.py
```
После запуска откройте в браузере: **[http://127.0.0.1:8080](http://127.0.0.1:8080)**

### Вариант 2: Стандартный модуль Python
```bash
python3 -m http.server 8080
```

### Вариант 3: Любой статический сервер
```bash
npx serve .
# или
open index.html
```

## 🤖 Отчет об использовании AI-инструментов

В соответствии с условиями тестового задания, при разработке использовался AI-ассистент:

* **Инструмент**: **Google Antigravity (модель Gemini 3.8 Flash High)**
* **Процесс взаимодействия**:
  1. **Анализ требований и дизайн-системы**:
     - Через подключенный Notion MCP агент выполнил поиск по рабочей области пользователя и извлек спецификацию *«Дизайн-система технических и прикладных проектов (Workbench UI)»*.
     - Были зафиксированы строгие правила: холст `#080808`, точечная сетка `radial-gradient(#1f1f24 0.85px, transparent 0.85px)`, микро-скругления 2–4 px, отказ от аморфных теней в пользу тонких разделителей `1px solid`, монохромная акцентная кнопка (`#e6e6e4`).
  2. **Проектирование и кодогенерация**:
     - Разделение на модульную архитектуру: дизайн-токены (`tokens.css`), логика хранилища (`storage.js`), реактивный контроллер интерфейса (`app.js`).
     - Реализация всех 4 базовых требований ТЗ + расширенных возможностей (поиск, фильтрация, инлайн-редактирование, экспорт/импорт).
  3. **Тестирование и верификация**:
     - Запуск и проверка локального HTTP-сервера.
     - Проверка обработки крайних состояний (пустой список, отмена удаления, валидация полей).
